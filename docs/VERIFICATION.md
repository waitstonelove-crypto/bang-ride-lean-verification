## 2. 机器证明的发现（论文勘误级）

### 发现 1：论文附录 E 的序保持引理在 Assumption 5.1 原假设下为假

论文声称：`λₖ(tf) ≥ λⱼ(tf) ⟹ λₖ(t) ≥ λⱼ(t)`（∀ t ≤ tf）。
**反例**（`order_preservation_counterexample`，全假设字段机器验证）：
n=3, a=(5,0,-3), λ₀=(10,-1,-2), p≡0, tf=2；
对 (1,2)：λ₀₁ = -1 ≥ -2 = λ₀₂（且 a₁ = 0 ≥ a₂ = -3），
但 t=1 处 λ₁(1) = -1 < λ₂(1) = -2e^{-3} ≈ -0.0996。
失效机理：**双负终端协态对**（λ₀ₖ ≥ λ₀ⱼ 均 < 0）在指数衰减下反转序。
ψ(t) = 10e^{5(2-t)} - 1 - 2e^{-3(2-t)} ≥ 7 > 0（假设束的 ψ ≥ 0 也满足）。

### 发现 2：主定理需要附加假设（论文证明的隐含条件）

论文 §5 声称"不限制 ∂s̃ᵢ/∂x 的符号"，但：
- **序保持**需要轨迹分量非负 `∀ k t, 0 ≤ λ t k`（修正版定理 B；电池应用例 λ₀=(1,0,…,0) 满足）；
- **积分项比较**需要 `p ≥ 0`（相对灵敏度非负；电池应用例 (37) 全正，满足）。

修正版 `externallyPositive` 在此二假设下成立；VERIFICATION 立场：**结论在附加条件下为真，
论文定理陈述与证明之间存在未声明的符号条件**。

### 发现 3：主定理结论限于内点 (0, tf)

端点需单侧导数论证；论文结论为 a.e. t，内点集覆盖全测度，不影响其结论强度。
